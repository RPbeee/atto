# atto

[![CI](https://github.com/RPbeee/atto/actions/workflows/ci.yml/badge.svg)](https://github.com/RPbeee/atto/actions/workflows/ci.yml)

[ダウンロード](https://github.com/RPbeee/atto/releases) · [リリース履歴](CHANGELOG.md) · [開発への参加](CONTRIBUTING.md)

Go製の小さなターミナルエディタです。nanoに近いキー操作で、複数ファイルを独立したバッファとして編集できます。左右・上下の画面分割、プロジェクト内検索、矩形編集、シンタックスハイライトにも対応しています。

## インストール

[GitHub Releases](https://github.com/RPbeee/atto/releases)からOS・CPUに対応するアーカイブをダウンロードし、展開した`atto`（Windowsは`atto.exe`）を実行できます。Linux・macOS・Windowsのamd64 / arm64向けを用意しています。SHA256SUMSと依存ライセンスを同梱します。非公開リポジトリの場合はダウンロードにGitHubのアクセス権が必要です。

Goがインストールされている環境ではソースからインストールできます。非公開の場合は`GOPRIVATE=github.com/RPbeee/atto`の指定とGitHubへのGit認証も必要です。

```sh
go install github.com/RPbeee/atto@v0.3.0
```

Linux / macOSでCIを実行し、Windowsはクロスビルドを確認しています。Windows実端末での操作は未検証です。

## 起動

Go 1.23以降と、対話操作できるターミナルが必要です。

```sh
go build -buildvcs=false -o atto .
./atto notes.txt main.go
```

引数なしで起動すると空のバッファを開きます。存在しないファイル名も指定できます。初回ビルドでは依存パッケージの取得にネットワーク接続が必要です。

```sh
go run . file1.txt file2.txt
./atto -help
./atto -version
```

`-`から始まるファイル名は `./atto -- -notes.txt` のように指定してください。ファイルパスはカレントディレクトリ基準です。画面下部の `^S` は Ctrl-S を意味します。

## 主な操作

| 操作 | キー |
| --- | --- |
| ヘルプ | Ctrl-G / F1 |
| ファイルを追加で開く（エクスプローラ） | Ctrl-R → h/j/k/l・矢印 → Enter（`.`隠しファイル、`~`パス入力、q / Esc閉じる） |
| 空のバッファを追加 | Ctrl-N |
| 保存 | Ctrl-S |
| 名前を指定して保存 | Ctrl-O |
| 変更済みの全バッファを保存 | F2 |
| 前 / 次のバッファ | F5 / F6、Alt-[ / Alt-] |
| バッファ一覧から選ぶ | Ctrl-B → 上下 → Enter |
| 左右 / 上下に画面分割 | F3 / F4 |
| 操作するペインを切り替え | F7 / Alt-O |
| 現在のペインを閉じる | F8 |
| プロジェクト内検索 | Ctrl-P → ディレクトリ → 検索語 |
| 前回のプロジェクト検索結果 | Alt-P |
| 矩形選択・編集の開始 / 終了 | Alt-R |
| シンタックスハイライトの切り替え | F9 / Alt-H |
| 言語の指定 | Alt-L → `auto` / `off` / `go` / `python` など |
| 現在のバッファを閉じる | Ctrl-X |
| 全バッファを終了 | Ctrl-Q |
| カーソル移動 / ページ移動 | 矢印 / PageUp・PageDown |
| 行頭 / 行末 | Home・End / Ctrl-A・Ctrl-E |
| 行・列へ移動 | Ctrl-J → `行番号` または `行番号:列番号` |
| 検索 / 次の一致 | Ctrl-W / Alt-W |
| 全置換（現在のバッファ） | Ctrl-\ |
| Undo / Redo | Alt-U / Alt-E |
| 範囲選択の開始・解除 | Ctrl-Space / Ctrl-6 |
| 移動しながら範囲選択 | Shift + 矢印 |
| 選択範囲、または現在の行を切り取り | Ctrl-K |
| 選択範囲、または現在の行をコピー | Alt-6 |
| 内部クリップボードから貼り付け | Ctrl-U |
| 選択解除 | Esc |

選択を開始した後は通常の矢印キーでも範囲を広げられます。入力・切り取り・コピー・バッファ切り替えで選択を解除します。

入力欄は Enter で確定、Esc / Ctrl-C でキャンセル、Ctrl-U で全消去します。左右・Home・End・Backspace・Deleteで入力を編集できます。Altキーが使えない端末では、Escを押してすぐ対象のキーを押す操作も端末によって利用できます。バッファ切り替えにはF5 / F6もあります。

## 複数ファイルの扱い

- 上部にバッファの一覧を表示します。`*` は保存済みの内容との差分がある状態です。
- バッファごとに本文、保存先、カーソル、縦横のスクロール、Undo / Redo、改行形式を保持します。
- 同じファイルを再度開くと、既に開いているバッファへ移動します。シンボリックリンクによる別名も解決します。
- Ctrl-Xは現在のバッファだけを閉じます。最後のバッファを閉じると終了します。
- 未保存の変更がある場合、`y`で保存、`n`で破棄、Escでキャンセルします。名前のないバッファは保存先を入力します。
- Ctrl-Qの途中でキャンセルすると、全バッファを開いたまま編集に戻ります。それまでに保存したファイルは保存済みです。
- F2では変更済みのバッファを順番に保存します。キャンセルや失敗時はそこで停止します。それまでの保存は取り消されません。

## 画面分割

F3で左右、F4で上下の2ペインに分割します。複数ファイルを開いていれば新しいペインに次のファイルを表示し、一つだけなら同じファイルを表示します。分割済みの場合は向きを切り替えます。

F7 / Alt-Oで操作するペインを切り替え、F5 / F6やCtrl-Rでそのペインのファイルを変更します。同じファイルを両側に表示した場合、本文とUndo履歴を共有し、カーソルとスクロール位置はペインごとに保持します。

F8はペインを閉じます。ファイル自体を閉じる操作はCtrl-Xです。端末が狭いときは操作中のペインだけを表示し、広げると分割表示に戻ります。

## プロジェクト内検索

Ctrl-Pでディレクトリと検索語を指定します。ディレクトリ欄の初期値はカレントディレクトリ、2回目以降は前回の指定です。Ctrl-Uで入力を消して変更できます。

結果一覧は上下・PageUp・PageDown・Home・Endで選び、Enterで操作中のペインにファイルを開いて該当行・列へ移動します。Escで一覧を閉じ、Alt-Pで再表示できます。検索中のEscは検索をキャンセルします。

大文字・小文字を区別する文字列検索です。名前付きの編集中バッファは未保存の本文を検索します。検索結果は検索時点のスナップショットで、内容が変わって該当箇所が一致しない場合は再検索を案内します。

`.git`、`.hg`、`.svn`、`node_modules`、`vendor`、`dist`、`build`、`.cache`は除外します。シンボリックリンク、バイナリ、未対応の文字コード・改行、大きすぎるファイルはスキップします。`.gitignore`の個別ルールは解釈しません。検索は最大1,000一致・10,000ファイル・処理対象の本文合計64 MiBで停止し、到達した上限を表示します。

## 矩形編集

1. 矩形の左上にカーソルを置き、Alt-Rを押します。
2. 矢印で右下まで移動します。画面に選択した列が表示されます。
3. 入力で各行を同じ文字列に置き換え、Ctrl-Kで切り取り、Alt-6でコピーできます。
4. Ctrl-Uで矩形として貼り付け、Escで通常編集に戻ります。

**同じ列に連続して入力する場合**は、Alt-Rの後に上下だけで対象行を選び、文字を入力します。入力後も幅0の矩形を維持するので、複数文字を続けて入力できます。Backspace / Deleteは対象となる全行の列を削除します。

短い行への入力は空白で指定列まで補完します。矩形クリップボードは通常状態でも複数行の同じ列へ貼り付けられ、必要なら末尾に行を追加します。複数行の貼り付けは各行へ順番に対応させ、一回のUndoで戻せます。

矩形の列は画面上のセル数で指定します。編集した行のタブは空白へ展開し、全角文字・絵文字の途中を境界にした場合は、文字を壊さず該当部分を空白に置き換えます。Enterによる通常の改行はEscで矩形編集を終了してから行ってください。

## シンタックスハイライト

ファイル名・拡張子から言語を判別し、キーワード、文字列、コメント、数値、関数名などを色分けします。Go、Python、JavaScript / TypeScript、Rust、C / C++、HTML、CSS、JSON、YAML、TOML、Markdown、シェルなどを扱えます。拡張子から判別できないスクリプトは、対応する先頭のshebangから判別します。

F9 / Alt-Hで全体の色分けを切り替えます。Alt-Lでは現在のバッファの言語を指定できます。`auto`で自動判別へ戻し、`off`でそのバッファの色分けを無効にします。無名のバッファも言語を指定すれば色分けできます。未知の言語は入力エラーとし、現在の設定を保持します。

複数行のコメントや文字列は本文全体の文脈を考慮します。両ペインで同じ色分けを表示し、範囲選択・矩形選択では構文の文字色を保ったまま背景を強調します。言語設定や色分けの切り替えは本文や保存状態を変更しません。

色分けは256 KiB以下の本文を対象とします。それ以上の本文や色分け処理の失敗時は通常表示で編集を継続し、ステータスに`(plain)`を表示します。言語ごとの意味解析・型情報に基づく色分け、テーマ設定は未実装です。

## 保存と制約

UTF-8、LF / CRLF、UTF-8 BOMを扱い、改行形式・BOM・末尾改行の有無を保持します。無効なUTF-8、NUL、混在改行、CRだけの改行、8 MiBを超えるファイルは拒否します。

外部のプログラムが内容を変更・削除した場合、保存を拒否して編集内容を保持します。開き直す前にCtrl-Oで別名保存すれば作業を退避できます。既存ファイルへの別名保存は上書き確認が必要です。別バッファが開いている保存先への書き込みは拒否します。

新規ファイルの権限は `0600`、既存ファイルの通常の権限ビットは保存時に維持します。保存先と同じディレクトリへの一時ファイル作成・置き換えに必要な権限が必要です。

日本語、結合文字、絵文字のカーソル移動・削除・表示に対応します。表示結果は端末のフォントとUnicode対応にも依存します。タブ幅は4セルです。長い行は横スクロールします。最小画面サイズは24列×8行です。

nanoの完全互換ではありません。折り返し、OSのクリップボード、マウス操作、設定ファイル、自動保存、クラッシュ復旧、大容量ファイル向けの最適化は未実装です。

詳しい仕様は [docs/SPEC.md](docs/SPEC.md)、構成・開発手順は [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) を参照してください。

端末制御には [tcell v2](https://pkg.go.dev/github.com/gdamore/tcell/v2)、文字境界・表示幅には [uniseg](https://github.com/rivo/uniseg)、構文解析には [Chroma](https://github.com/alecthomas/chroma) を使用しています。
