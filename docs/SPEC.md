# atto 0.4.0 仕様

## 目的

nanoに近い非モーダルな操作を持つGo製のターミナルエディタ。複数ファイルを一度に開き、編集中に追加・切り替え・保存・終了できることを基本要件とする。

## CLI

`atto [options] [file ...]`

- `-help`: 起動方法とオプションを表示して終了。
- `-version`: バージョンを表示して終了。
- ファイルなし: 無名の空バッファを一つ作成。
- 複数ファイル: 指定順に開き、最初を選択。同じ正規化パスは重複作成しない。
- 読み込み失敗: 端末を初期化する前にエラーを表示し、終了コード1で終了。ファイルは変更しない。
- 途中でファイルを開く際の失敗: エラーを画面内に表示し、既存の編集を継続。
- 対話型ターミナルが必要。パイプ入力による本文読み込みは対象外。

## バッファ

各バッファは以下を持つ。

| 状態 | 定義 |
| --- | --- |
| パス | 絶対パス。既存のシンボリックリンクを解決。無名なら空 |
| 本文 | rune列。内部改行はLF |
| カーソル | 本文内のruneオフセット |
| ビューポート | 表示開始行と横方向の表示セルオフセット |
| 保存済み本文 | 変更判定の基準となる文字列 |
| ディスク状態 | ファイルの存在と読み込んだバイト列のSHA-256 |
| 形式 | LFまたはCRLF、BOMの有無 |
| 履歴 | バッファ専用Undo / Redoスタック |

変更判定は保存済み本文との比較。Undoで保存時の本文に戻れば変更マークも消える。切り替えで本文・カーソル・スクロール・履歴を維持する。検索語と内部クリップボードは全バッファで共有する。通常選択・矩形選択はバッファまたはペインの切り替えで解除する。

ファイル同一性は解決後のパスで判定する。ハードリンクの同一inode判定は行わない。ダングリングシンボリックリンクと存在しない親ディレクトリはエラーにする。

## 編集

- 通常文字はカーソル位置へ挿入。Enterは改行、Tabはタブを挿入。
- 横移動とBackspace / Deleteは結合文字・絵文字を含む書記素クラスタを単位とする。行末と行頭では改行をまたぐ。
- 縦移動は表示セル上の列を維持する。短い行を通過しても目標列を保持する。
- Ctrl-Jで1始まりの行・rune列を指定。存在する行、行末までの列のみ許可する。
- 行番号・ステータス列番号は1始まり。列番号は表示セル数ではなくrune数で数える。
- 範囲選択中の入力・削除・貼り付けは選択範囲を置換する。
- 選択なしのCtrl-K / Alt-6は現在行を対象とする。末尾以外では改行も含む。
- クリップボードはセッション内で共有する。OSのクリップボードとは同期しない。
- Bracketed paste対応端末では貼り付け全体を一つの編集として扱う。貼り付け中の入力をコマンドとして解釈しない。
- 貼り付けのCRLF / CRはLFへ変換し、NULは除去する。入力欄への貼り付けは改行を取り除き、入力を自動確定しない。

### Undo / Redo

各編集の直前の本文とカーソルを記録する。通常の入力は一文字ごと、括弧付き貼り付けと全置換は一回でUndoできる。新しい編集はRedoを破棄する。保存操作は履歴を消さない。

各スタックは最大200件、本文UTF-8バイト数の合計16 MiB以内。古い履歴から削除する。本文はrune列、履歴は全文スナップショットであり、巨大な本文での頻繁な入力は最適化対象として残す。

## 検索・置換

- 大文字・小文字を区別するリテラル検索。正規表現は扱わない。
- カーソルより後ろの一致を探し、末尾に達すると先頭へ戻る。
- Alt-Wは最後の検索語を使用。空の検索語は検索しない。
- Ctrl-\は検索語、置換語を入力し、確認後に現在のバッファの全一致を置換する。
- 置換文字列を空にすると削除できる。全置換は一つのUndo対象。

## 画面分割とビュー

最大2ペイン。F3は左右、F4は上下。単一ペインからは2つ目を作成し、分割済みでは向きを変更する。2つ目には次のバッファを表示し、バッファが一つの場合は同じ本文を表示する。

F7 / Alt-Oでフォーカスを切り替え、F8でフォーカス中のペインを閉じる。ペインを閉じてもバッファは保持する。通常の編集・保存・検索・ファイル切り替え・追加オープンはフォーカス中のペインを対象とする。

各ペインは表示バッファ、カーソル、縦横スクロール、縦移動の目標列を持つ。バッファを切り替えて戻った場合にもペイン専用の位置を復元する。同じバッファの本文・保存状態・Undo / Redoは共有する。片側の本文編集後、他方のカーソル位置を前後の共通部分に基づいて補正し、常に本文内に収める。

左右分割は49列以上、上下分割は12行以上で表示。サイズが足りなければフォーカス中のペインだけを表示し、分割状態は保持する。各分割ペインの見出しにファイル名を表示し、操作中のペインを強調する。ページ移動はペイン内の本文表示行数を基準とする。

Ctrl-Xでバッファを閉じた場合、そのバッファを表示していた全ペインを残存バッファへ差し替える。最後のバッファを閉じた場合はペインを破棄して終了する。

## プロジェクト内検索

Ctrl-Pはディレクトリ入力、検索語入力の順で尋ねる。既定ディレクトリは初回がカレントディレクトリ、以降は最後の指定。空の検索語は実行しない。Alt-Pは最後の結果一覧を再表示する。

指定ディレクトリを再帰的に探索し、UTF-8テキストを行単位でリテラル検索する。大文字・小文字は区別し、同じ行に複数の非重複一致があれば別々の結果とする。各結果はファイルパス、1始まりの行・rune列、本文プレビューを持つ。

同じパスで開いているバッファはディスクよりも検索開始時の本文を優先する。指定ディレクトリ内の名前付き新規バッファも含む。無名バッファは対象外。検索は読み取り専用で、バッファ保存を伴わない。

`.git`、`.hg`、`.svn`、`node_modules`、`vendor`、`dist`、`build`、`.cache`というディレクトリを探索から除外する。`.gitignore`や独自除外ルールは未実装。シンボリックリンクを追跡しない。非通常ファイル、無効なUTF-8、NUL、混在改行・CR単独改行、8 MiB超過、読み込み失敗はスキップし、件数を表示する。

上限は1,000一致、10,000ファイルの検査、正常に読み込んだ本文の累計64 MiB。上限に達するとその時点の結果と停止理由を表示する。探索順はディレクトリの名前順。探索に現れない名前付き新規バッファは最後にパス順で検索する。

検索用goroutineは検索開始時点の本文スナップショットだけを参照し、UIの状態を直接変更しない。結果は専用チャネルと端末の通知イベントで渡し、メインのイベントループが反映する。検索中も再描画とキャンセルを処理する。新しい検索の開始時には古い検索をキャンセルし、古い結果を反映しない。終了時には検索をキャンセルし、goroutineの終了後に端末を復元する。

一覧では上下・PageUp・PageDown・Home・Endで選択し、Enterでフォーカス中のペインに結果ファイルを開いて該当行・列へ移動する。開いているファイルを読み込み直さず未保存の本文を保持する。該当箇所が検索語と一致しなくなった場合は再検索を案内し、古い位置への移動を行わない。Esc / Ctrl-Cで検索をキャンセルして一覧を閉じる。

## 矩形編集

Alt-Rで矩形選択を開始・終了する。初期の矩形はカーソル位置の幅0・1行。上下左右、Home / End、PageUp / PageDownで終点を動かす。列は表示セル数、行は本文行で指定する。行末を越える仮想列も指定できる。通常選択と矩形選択は排他的。

| 操作 | 動作 |
| --- | --- |
| 文字入力・Tab | 選択列を各行で同じ文字列に置換し、入力直後の幅0の矩形を維持 |
| Backspace / Delete | 選択列を削除。幅0ならそれぞれ前 / 次の1セルを削除 |
| Ctrl-K | 矩形を専用クリップボードへ切り取り、選択解除 |
| Alt-6 | 矩形を専用クリップボードへコピー、選択解除 |
| Ctrl-U | クリップボードの行を順に各行へ対応させて貼り付け |
| Enter | メッセージで通常の改行前に矩形を終了するよう案内 |
| Esc / Alt-R | 矩形を終了 |

入力後の幅0の矩形は対象行を維持し、続けて入力した文字を各行へ挿入する。複数行の括弧付き貼り付けでは入力行を対象行へ順に対応させ、入力行が多ければ対象行・本文を拡張する。入力行が対象行より少なければ残りの選択部分を空文字で置換する。1行の入力は対象となる全行へ繰り返す。

短い行への入力は指定列まで空白で補完する。削除だけなら行末以降に空白を追加しない。矩形コピーでは空白補完により全行を同じ表示幅にする。矩形クリップボードを通常状態で貼り付けた場合も、現在の表示列から複数行に挿入し、必要なら本文末尾に行を追加する。通常の切り取り・コピーでクリップボードの矩形属性を解除する。

対象となる行のタブは空白へ展開し、挿入するタブも挿入列から次の4セル境界までの空白に変換する。矩形境界が全角文字・絵文字・制御文字の途中を切る場合、その部分は同じ幅の空白にして書記素を分断しない。幅0の挿入が全角文字の途中にある場合も、その文字の左右を空白に分けて挿入する。

矩形置換・切り取り・貼り付けは複数行をまとめて一つの履歴に記録する。Undo / Redoは本文とカーソルを戻し、矩形選択は解除する。選択範囲はフォーカス中のペインだけに表示する。短い行の行末以降の選択範囲も強調表示する。

## シンタックスハイライト

起動時は有効。F9 / Alt-Hで全体の表示を切り替え、Alt-Lでバッファごとの言語を指定する。言語入力は`auto`（自動判別）、`off`（そのバッファを無効化）、Chromaの言語名・エイリアスを受け付ける。入力が空なら`auto`、未知の言語ならエラー表示して既存設定を保持する。設定はセッション内のみで、本文・変更マーク・Undo履歴には影響しない。

自動判別はファイル名をChromaの登録パターンに照合する。拡張子から判別できない場合のみ、先頭のshebangを最大512 runeまで読み、Python、sh / bash / zsh / ksh、Node.js、Ruby、Perl、PHP、fishを判別する。`/usr/bin/env`経由も扱う。判別不能な本文はPlain表示。通常の本文をヒューリスティックに推測する機能はない。

本文全体をトークン化し、キーワード、文字列、コメント、数値、関数、組み込み名・型・タグ、演算子、Markdownの見出し・強調などに色・属性を割り当てる。複数行のコメント・文字列を前の行から続く文脈で表示する。Goでは未完のブロックコメント・raw文字列を本文末尾まで、未完の通常文字列・文字リテラルを行末まで色分けする。その他の未完の構文の扱いは言語のlexerによる。

色分けは表示専用であり、lexerの出力で本文を置き換えない。トークンの位置はruneオフセットへ変換して保存する。日本語・結合文字・絵文字・タブ・横スクロールの描画は従来の表示セル計算を使用する。範囲選択・矩形選択では構文の前景色を維持し、選択背景を重ねる。入力欄・ステータス・検索結果一覧・行番号には構文色を適用しない。

キャッシュはバッファごとに本文の変更世代・保存先パス・言語指定をキーとして保持する。編集・Undo / Redoで世代を更新し、別名保存で拡張子が変わった場合も再判別する。カーソル移動・スクロール・リサイズ・同じバッファの2ペイン表示ではキャッシュを共有・再利用する。全体表示が無効な間の編集も、再び有効にした際に最新本文を解析する。

本文UTF-8バイト数が256 KiBを超える場合はトークン化を行わず通常表示にする。lexerの初期化・実行エラー時も通常表示とし、ステータスに`(plain)`を表示する。色分けは256色対応を想定し、実際の色・太字・斜体の表示は端末の対応に依存する。LSP等の意味解析、テーマ設定、言語別の追加設定は対象外。

## 保存

1. 保存先を正規化し、他の開いているバッファの保存先と競合しないことを確認。
2. 通常保存では読み込み・直前の保存時のディスク状態と比較。
3. 別名保存では既存保存先に上書き確認を表示。この時点のディスク状態を保存。
4. ファイルの存在・内容が基準と異なる場合は保存を拒否。
5. 既存ファイルに書き込み権限ビットが一つもなければ保存を拒否。
6. 改行・BOMを復元。同じディレクトリに一時ファイルを作成し、通常の権限ビットを設定、書き込み、Sync、Close。
7. ディスク状態を再確認し、Renameで保存先を置き換える。
8. 成功後にバッファのパス、保存済み本文、ディスク状態を更新。

失敗時は編集内容と変更マークを保持する。一時ファイルは通常の失敗時に削除する。作成する新規ファイルは0600。既存ファイルは通常の権限ビットを維持する。親ディレクトリは自動作成しない。編集後の保存内容も8 MiB以内を要求する。

既存シンボリックリンクへの保存は解決後の対象を置き換え、リンク自体を保持する。原子的な置き換えはLinux / macOSの通常のローカルファイルシステムを想定する。

### 保存の保証範囲

本文の部分書き込みを避けるための一時ファイル方式であり、ファイルロックや複数ファイルのトランザクションは実装しない。最終確認とRenameの間の外部書き込みは完全には防げない。メタデータだけの外部変更は内容衝突と判定しない。

inodeを置き換えるのでハードリンク先は更新しない。所有者・ACL・拡張属性・特殊な権限ビットは保存対象外。ディレクトリのfsyncは行わず、停電時の永続性までは保証しない。

## クローズ・終了

Ctrl-Xは現在のバッファのみを閉じる。最後のバッファを閉じると終了する。Ctrl-Qは全バッファを終了する。

| 確認への入力 | 動作 |
| --- | --- |
| y / Y | 保存後に続行。保存先入力・上書き確認・保存の失敗では編集へ戻る |
| n / N | 保存せず続行 |
| Esc / Ctrl-C | キャンセルして編集へ戻る |
| その他 | 確認を継続 |

全体終了中は全ての確認が完了するまでバッファを閉じない。途中キャンセル時は全バッファを保持する。確認途中で保存したファイルの保存結果は保持する。

F2は変更済みバッファを開いた順に保存。未保存の無名バッファは保存先を尋ねる。途中失敗・キャンセル時は停止し、それまでの保存結果を保持する。

SIGINT / SIGTERMを外部から受信した場合、端末状態を復元してエラー終了する。未保存データを自動保存する機能はない。

## 画面

上部に保存先とタブ一覧、中央に行番号と本文、下部に現在位置・形式・メッセージ・操作ガイドを表示する。未保存の変更があれば`*`を付ける。タブ一覧と本文は選択中のバッファ・カーソルが見えるようにスクロールする。

文字は書記素クラスタ単位で描画し、全角文字とタブを表示セル数で計算する。ASCII制御文字はキャレット記法で表示する。長い行は横スクロールし、折り返さない。タブ幅は4セル固定。

24列×8行未満ではサイズ変更メッセージを表示する。画面のリサイズ後に再描画する。ヘルプとバッファ一覧は一時的な画面で、本文を変更しない。

## 対象外

nano完全互換、3つ以上のペイン、意味解析に基づく色分け、テーマ設定、自動インデント、設定ファイル、OSクリップボード、マウス、折り返し、正規表現、非UTF-8、混在改行、バイナリ、大容量最適化、バックアップ・自動保存・復旧、ファイル監視。

## ファイルエクスプローラ

Ctrl-Rは親・現在・プレビューの3列を持つエクスプローラを開く。起点は現在のバッファのあるディレクトリ（無題ならカレントディレクトリ、または前回の位置）。ディレクトリを先頭に、名前の大文字小文字を無視して並べる。

| キー | 動作 |
| --- | --- |
| j / k / ↓ / ↑ | 選択移動 |
| h / ← / Backspace | 親ディレクトリへ（元のディレクトリを選択） |
| l / → / Enter | ディレクトリなら移動、ファイルなら開く |
| g / G / Home / End | 先頭 / 末尾 |
| PgUp / PgDn | ページ移動 |
| . | 隠しファイルの表示切り替え |
| ~ / / / : | 従来の「Open file:」パス入力へ切り替え（現在のディレクトリを初期値にする） |
| q / Esc / Ctrl-C | 閉じる |

プレビューはディレクトリの内容、またはUTF-8テキストの先頭約8KiBを表示する。バイナリ・非UTF-8は注記のみ。エクスプローラ表示中のキー入力と貼り付けは本文に影響しない。
