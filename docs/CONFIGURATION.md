# 設定とlint

attoは起動時にユーザーの設定ディレクトリの `atto/config.json` を読み込む。
Linuxでは `$XDG_CONFIG_HOME/atto/config.json`、未設定なら `~/.config/atto/config.json`。
macOSは `~/Library/Application Support/atto/config.json`、Windowsは `%AppData%/atto/config.json`。
別の場所を使う場合は `atto -config /path/to/config.json file.go` を指定する。
既定のファイルがない場合はlint無効。明示指定したファイルがない場合、JSON・設定値が不正な場合は起動前にエラーを表示する。設定の変更は次回起動時に反映される。

## Goの設定例

```json
{
  "lint": {
    "on_save": true,
    "timeout_seconds": 10,
    "rules": [
      {
        "pattern": "*.go",
        "command": ["go", "vet", "./..."],
        "directory": "{dir}"
      }
    ]
  }
}
```

[サンプル](../examples/config.json)を設定ファイルにコピーして使える。
Goのインストールと、対象ディレクトリから `go vet ./...` を実行できる環境が必要。

| 設定 | 動作 |
| --- | --- |
| `on_save` | `true` で保存成功後に自動実行。既定は `false` |
| `timeout_seconds` | 実行制限。既定10秒、1〜300秒 |
| `rules` | ファイルごとのルール。上から最初に一致したものを使う |
| `pattern` | ファイルのベース名に対するglob。例 `*.go`、`*.py` |
| `command` | 実行ファイルと引数の配列。シェルの引用符・パイプ・変数展開は使わない |
| `directory` | 作業ディレクトリ。省略時は対象ファイルの親。相対パスもその親を基準とする |

コマンド引数と作業ディレクトリの `{file}` は対象の絶対パス、`{dir}` はその親の絶対パスに置換する。
ファイル単体を検査するツールには `"command": ["my-linter", "{file}"]` のように指定する。
外部lintツールは利用者がインストールする。設定したコマンドは利用者の権限で実行される。
プロジェクト内の設定ファイルは自動では読み込まない。

## 操作

- **Ctrl-S / F2**: 保存成功後、`on_save` が有効なら対応するlintをバックグラウンドで実行。
- **F10**: 現在の保存済みバッファを手動でlint。`on_save: false` でも使える。
- **F11**: 現在のバッファの診断一覧。
- 一覧の **↑ / ↓** で選択、**Enter** で診断先のファイル・行・列に移動、**Esc** で戻る。
- 一覧でも **F10** で再実行できる。

未保存の変更がある場合、手動実行は保存を促す。入力ごとのlintや自動修正は行わない。
`path:line:column: message` または `path:line: message` 形式の標準出力・標準エラーを診断として扱う。
行・列は1始まり、列はエディタのUnicode文字位置として扱う。ツールがバイト列や表示セル単位で報告する場合、非ASCII文字を含む行で列位置がずれることがある。
相対パスはコマンドの作業ディレクトリを基準に解決する。
診断形式のない出力は、診断が0件の場合に一覧画面へテキストとして表示する。
終了コードが非0でも診断は表示する。コマンド未検出・タイムアウトは状態表示と一覧に出る。

## 実行管理

編集操作はlintの完了を待たない。ファイルごとに直近の実行だけを保持し、再保存・再実行時には以前の実行をキャンセルする。
バッファが編集されたらその結果を無効にし、実行中なら次のイベント処理でキャンセルする。別名保存・バッファを閉じる場合にも古い結果を使わない。
エディタ終了時は実行中のコマンドをキャンセルして回収する。
stdout/stderrの保持は合計1MiB、診断は最大1000件。ANSI色と制御文字は除去する。
タイムアウトで停止する対象は直接起動したプロセス。子プロセスを独立起動するツールの全プロセスを終了する保証はない。
