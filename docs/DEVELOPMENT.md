# 開発メモ

## 構成

| ファイル | 責務 |
| --- | --- |
| `main.go` | CLI、端末初期化・復元、イベントループ、終了シグナル |
| `buffer.go` | 本文編集、カーソル、書記素移動、履歴、検索・置換 |
| `storage.go` | UTF-8検証、形式保持、パス解決、外部変更チェック、安全な保存 |
| `editor.go` | 複数バッファ、キー操作、入力・確認ダイアログ、選択、クリップボード |
| `render.go` | タブ、本文、スクロール、状態表示、ヘルプ、一覧 |
| `panes.go` | 2ペインの分割、ビュー状態・フォーカス管理、共有本文変更時の位置補正 |
| `rectangle.go` | 表示セル単位の矩形選択、複数行編集、矩形クリップボード |
| `project.go` | 再帰検索、除外・上限・キャンセル、バックグラウンド実行、結果一覧・移動 |
| `syntax.go` | Chromaによる言語判定・構文色、Goの未完構文、本文世代ごとの色分けキャッシュ |
| `*_test.go` | 本文・ファイルIO・tcellシミュレーションを通した操作テスト |

端末イベント処理と状態変更はメインの一つのgoroutineで行う。シグナル受信用goroutineは端末イベントキューへの通知のみを行う。プロジェクト検索用goroutineは本文スナップショットを受け取り、結果をチャネルで返す。検索結果の適用とペイン管理はメインgoroutineが行う。UI、本文、ファイルIOの責務を分け、本文と保存処理は端末なしでもテストできる。

## ビルドと検証

```sh
go build -buildvcs=false -o atto .
go test ./...
go test -race -cover ./...
go vet ./...
```

ビルド時の`-buildvcs=false`は、Git情報のない作業環境でもビルドできるように指定している。通常のGitリポジトリでは省略可能。

Unixの実端末相当のPTYで、入力・2ファイルの保存・切り替え・左右/上下の分割・フォーカス・矩形入力・プロジェクト検索/移動・終了時の端末復元を確認するスモークテストも用意している。ビルド後にPython 3で実行できる。

```sh
python3 tools/pty_smoke.py
```

Makefileも利用できる。

```sh
make build
make test
make check
```

`tcell.NewSimulationScreen`でキーイベント、画面サイズ変更、日本語表示、バッファ一覧を検証する。テストは一時ディレクトリのファイルのみを変更する。

主要な回帰テストは、バッファ間の履歴独立性、全保存、未保存終了のキャンセル、保存失敗後の継続、保存先衝突、上書き確認後の外部変更、UTF-8 / CRLF / BOMの往復、シンボリックリンク、日本語・結合文字・絵文字の削除、範囲選択、括弧付き貼り付けを扱う。追加機能では、共有本文を表示するペインの位置独立性・閉じたバッファの差し替え・狭い画面での分割保持・短い行とUnicodeを含む矩形編集・矩形操作のUndo・プロジェクト検索の未保存本文優先・除外・上限・キャンセル・古い結果の検証を扱う。構文色分けは複数行・未完のコメント/文字列、言語判別、手動指定、別名保存、Undo/Redo、Unicodeの位置、分割画面、選択背景、サイズ上限、無効化を検証する。

## 手動確認

1. `./atto a.txt b.txt`で2ファイルを開く。
2. それぞれ入力し、F5 / F6で本文と位置が戻ることを確認。
3. Ctrl-Sで片方のみ保存し、もう片方の変更マークが残ることを確認。
4. Ctrl-Q → Escで編集に戻る。Ctrl-Q → yで残りを保存して終了。
5. 再度起動し、Ctrl-Rで追加のファイルを開く。
6. 日本語・絵文字・結合文字、長い行、端末リサイズ、貼り付けを試す。
7. 開いたファイルを別端末から変更し、保存が拒否されることを確認。

8. F3 / F4で2ペインを作り、F7でフォーカスを切り替える。F8でペインを閉じてもファイルは開いたままになることを確認。
9. Alt-R → 下矢印で複数行を選び、文字を続けて入力。短い行の空白補完・Ctrl-K / Alt-6 / Ctrl-U・Undoを確認。
10. Ctrl-Pでプロジェクトのパスと検索語を指定し、結果から該当行へ移動。未保存の本文を検索でき、Escで検索をキャンセルできることを確認。

11. `.go`や`.py`を開いて構文の色を確認。Alt-Lで言語を変更し、F9で切り替える。分割・範囲選択・矩形選択でも色と文字位置が保たれることを確認。

CI・配布物・GitHubリリースの運用は[RELEASING.md](RELEASING.md)を参照してください。
