# atto v0.5.0

## 自動lintと設定ファイル

- ユーザー設定JSONと `-config` オプションを追加。
- ファイル名globごとに外部コマンドを指定し、保存成功後にバックグラウンドでlintを実行。
- F10で手動lint、F11で診断一覧、Enterで診断先のファイル・行・列へ移動。
- タイムアウト、出力・診断件数の上限、再実行・編集・バッファを閉じる際のキャンセル。
- 編集後の古い診断結果を無効化し、ファイルごとに結果を管理。

既定ではlintは無効です。Linuxでは `~/.config/atto/config.json` に設定を置きます。
設定例は `examples/config.json`、詳細は `docs/CONFIGURATION.md` を参照してください。
lintツールは別途インストールしてください。対象は保存済みファイルです。

## 配布物

Linux・macOS・Windowsのamd64 / arm64向けアーカイブとSHA256SUMSを添付します。
依存ライセンスを各アーカイブに同梱します。Windows実端末での操作は未検証です。
