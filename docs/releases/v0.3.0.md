# atto v0.3.0

Go製のnano風ターミナルエディタの初回リリースです。

- 複数ファイルの編集と独立したUndo / Redo。
- 左右・上下の2ペイン分割。
- プロジェクト内検索と該当行への移動。未保存の本文にも対応。
- 矩形選択・複数行への列入力・切り取り・貼り付け。
- Go、Python、JavaScript / TypeScriptなどのシンタックスハイライト。
- 日本語・結合文字・絵文字、LF / CRLF、UTF-8 BOMに対応。
- 未保存の終了確認と、ディスク上の外部変更による上書き防止。

## 配布物

Linux / macOSは`.tar.gz`、Windowsは`.zip`をダウンロードして展開し、`atto`または`atto.exe`を実行してください。各OSでamd64 / arm64を用意しています。`SHA256SUMS`でアーカイブのチェックサムを確認できます。アーカイブには操作方法・仕様書・依存パッケージのライセンスを同梱しています。

```sh
./atto file1.txt file2.txt
```

Ctrl-G：ヘルプ、Ctrl-S：保存、Ctrl-Q：終了。F3 / F4：分割、F7：ペイン切り替え、Ctrl-P：プロジェクト検索、Alt-R：矩形編集、F9：色分け切り替え。

Linux / macOSはCIで検証します。Windows配布物はクロスビルドによるもので、Windows実端末での操作確認は行っていません。

編集対象はUTF-8テキストで最大8 MiB、構文色分けは256 KiB以下です。画面分割は最大2ペイン。自動保存・クラッシュ復旧・OSクリップボード・マウス操作は未実装です。
