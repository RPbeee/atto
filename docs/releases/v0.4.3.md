# atto v0.4.3

シンタックスハイライトの小さな修正リリースです。

- Makefileの`ifeq` `ifdef` `else` `endif` `define` `endef` `include`などをキーワード色で表示（従来はエラー色）。
- `.intel_syntax`を含む`.s` / `.S`（Intel記法のGNUアセンブラ）をGAS用の色分けにし、`[rip+msg]`の`+`がエラー色になる問題を修正。

## 配布物

Linux / macOSは`.tar.gz`、Windowsは`.zip`をダウンロードして展開し、`atto`または`atto.exe`を実行してください。各OSでamd64 / arm64を用意しています。`SHA256SUMS`でアーカイブのチェックサムを確認できます。
