# atto v0.4.1

依存ライブラリの更新リリースです。機能の変更はありません。

- tcell 2.9.0 → 2.13.10（Windowsでの貼り付け、幅の広い文字の表示、キー入力まわりの修正）
- chroma 2.20.0 → 2.27.0（構文色分けの修正と言語の追加）
- uniseg 0.4.3 → 0.4.7（異体字セレクタを含む文字の幅計算の修正）
- ソースからビルドするにはGo 1.25以降が必要になりました。配布物を使う場合は影響ありません。

## 配布物

Linux / macOSは`.tar.gz`、Windowsは`.zip`をダウンロードして展開し、`atto`または`atto.exe`を実行してください。各OSでamd64 / arm64を用意しています。`SHA256SUMS`でアーカイブのチェックサムを確認できます。
