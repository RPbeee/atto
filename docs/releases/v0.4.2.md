# atto v0.4.2

シンタックスハイライトの修正リリースです。

- アセンブリ（`.s` / `.S`）で`#`・`//`のコメントが色分けされない問題を修正。
- 色分けされない、または別の言語として判定されていた拡張子を補正。
  - `.cu` `.cuh` `.mm` `.glsl` `.less` `.fsx` `.cljs` `.ron` `.tfvars` `.j2` `.mdx` などを既存の言語に対応付け。
  - `.conf` `.gitignore` `.dockerignore`などは`#`コメントを色分け。
  - `go.mod`をGoとして扱う。
  - `.m`（Objective-C / MATLAB / Mathematica）と`.v`（Verilog / Coq / V）は内容から判定。判定が違う場合はAlt-Lで言語を指定できます。

## 配布物

Linux / macOSは`.tar.gz`、Windowsは`.zip`をダウンロードして展開し、`atto`または`atto.exe`を実行してください。各OSでamd64 / arm64を用意しています。`SHA256SUMS`でアーカイブのチェックサムを確認できます。
