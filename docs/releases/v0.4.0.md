# atto v0.4.0

Ctrl-Rのファイル選択をyazi風のTUIファイルエクスプローラに変更しました。

- 親・現在・プレビューの3列表示。プレビューはディレクトリの内容、またはUTF-8テキストの先頭を表示します。
- `h/j/k/l`・矢印で移動、Enterで開く、`g/G`で先頭・末尾、`.`で隠しファイルの表示切り替え、`q` / Escで閉じます。
- `~`で従来のパス入力に切り替えられます。存在しない新規ファイルを開くときに使います。
- 現在のファイルのあるディレクトリから開始します。

## 配布物

Linux / macOSは`.tar.gz`、Windowsは`.zip`をダウンロードして展開し、`atto`または`atto.exe`を実行してください。各OSでamd64 / arm64を用意しています。`SHA256SUMS`でアーカイブのチェックサムを確認できます。

Windows配布物はクロスビルドによるもので、Windows実端末での操作確認は行っていません。
